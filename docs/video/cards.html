Beat 7 · what is not true yet

Three honest limits

A run takes minutes. A gateway request gets thirty seconds and a specialist reading with a model takes about a hundred, so the chore runs in the background and the page waits.
Private repositories are not supported. Reads use the public API with no credential, deliberately: a read path that needs a token is a read path that can be used to write.
The ledger is append only by interface, not by storage policy. The custody chain makes an edit from outside our code detectable. It does not make a row immutable, and the site says so on the page that shows the chain.
